# Changelog

## v0.1.0
- Initial implementation of Music Cleaner.
- Implemented persistent favorite songs whitelist storage.
- Added batch deletion routine with filesystem size calculation and confirmation dialogs.
- Integrated compact favorite star toggle into CustomSongWidget on level pages with refined margins.
- Replaced redundant USE button in CustomSongCell with the favorite star toggle directly beside the trash button.
- Added search popup dialog in GJSongBrowser to search downloaded tracks by title, artist, or song ID.
- Added quick-access button in Saved Levels browser opening the custom songs browser (GJSongBrowser).
- Added in-game info dialog with feature summary and developer attribution.
- Implemented deletion safeguards for favorited tracks.
