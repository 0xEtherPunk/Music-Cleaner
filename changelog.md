# Changelog

## v0.1.0
- Initial implementation of Music Cleaner.
- Implemented persistent favorite songs whitelist storage.
- Added smart batch deletion routine with filesystem size calculation and confirmation dialogs.
- Integrated compact favorite star toggle into CustomSongWidget on level pages.
- Added selection checkbox, star button, and delete button to CustomSongCell rows.
- Added quick-access button in Saved Levels browser opening the custom songs browser (GJSongBrowser).
- Implemented deletion safeguards for favorited tracks.
